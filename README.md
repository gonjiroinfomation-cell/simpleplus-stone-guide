# Simple+ 天然石ガイド

Simple+の天然石・真珠・貝などを紹介する静的サイトです。既存87項目を維持し、掲載作品のアイオライト・アンダリュサイト・サードニクス・桜メノウを追加しました。

## 編集

- `stones.json`: 石の説明。`name`、五十音の行を示す`kana`、ひらがなの`reading`、`description`が必須です。
- `aliases`: 検索用の別名。`care`、`treatment`、`note`: 詳細説明。`sources`: 参考資料URL。`product`: 実在する作品例へのリンク。未確認の加工を個別作品の事実として記載しないでください。
- `build.mjs`: `node build.mjs`でテンプレートとデータから`index.html`を出力します。JavaScriptが無効でも一覧と説明を読めます。
- `script.js`: 石名検索。全角・半角、ひらがな・カタカナを正規化します。
- `style.css`: スマートフォン優先のレイアウト。アクセントはBASEに合わせたくすみローズ`#7B465F`です。

外部ライブラリ・外部フォント・追跡ツールは使用しません。写真の追加時は実物写真を使い、石名と写真の対応・使用権限を確認してください。現在は写真なしで完結する構成です。

## 公開

GitHub Pagesの既存mainブランチ配信を使用します。`stones.json`を変更した後は必ず`node build.mjs`を実行し、生成した`index.html`も同じコミットに含めてください。
