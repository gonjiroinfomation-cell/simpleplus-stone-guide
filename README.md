# Simple+ 天然石ガイド

天然石アクセサリーブランド **Simple+** の天然石紹介ページです。石名を「あ・か・さ・た・な・は・ま・や・ら・わ」の見出しから探せます。

スマートフォンを優先したレスポンシブデザインで、GitHub Pagesにそのまま公開できる、外部ライブラリ不要の静的サイトです。

## ファイル構成

```text
.
├── index.html   # ページの構造
├── style.css    # 配色・レイアウト・レスポンシブ表示
├── script.js    # 天然石データと一覧の描画処理
└── README.md    # この説明書
```

## 石を追加・編集する方法

天然石の情報は `script.js` 冒頭の `STONES` 配列にまとめています。新しい石は、次の形式で1件追加してください。

```js
{
  name: "石名",
  kana: "あ",
  description: "簡潔な特徴説明",
},
```

- `name`: 画面に表示する石名
- `kana`: `あ`・`か`・`さ`・`た`・`な`・`は`・`ま`・`や`・`ら`・`わ` のいずれか
- `description`: 石の色や質感などを伝える短い説明

保存すると、指定した行の一覧へ自動的に追加されます。同じ行の中では石名のあいうえお順に並びます。

## ローカルで確認する方法

ファイルを直接開いても表示できます。ローカルサーバーで確認する場合は、リポジトリのフォルダーで次を実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開いてください。

## GitHub Pagesで公開する方法

1. GitHubでこのリポジトリを開き、**Settings** を選びます。
2. 左側の **Pages** を選びます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** を `main`、フォルダーを `/(root)` にして **Save** を押します。
5. デプロイ完了後、Pages画面に表示されるURLを開きます。

通常、反映には数分かかります。公開後のURLは次の形式です。

```text
https://gonjiroinfomation-cell.github.io/simpleplus-stone-guide/
```

## 補足

- 外部フォント、画像、JavaScriptライブラリは使用していません。
- PC、タブレット、スマートフォンの画面幅に応じてカードの列数が変わります。
- GitHub Pagesの公開設定はリポジトリ管理者が行ってください。
